## Grille des 5 indicateurs

| # | Indicateur | Définition (ce qu'on mesure) | Source de données | Avant | Après | Conversion en € (formule) | Piège à éviter |
|---|---|---|---|---|---|---|---|
| 1 | **Temps** | Heures gagnées ET réallouées | Relevés d'activité, journaux, sondages hebdo | | | | Compter des heures jamais réallouées |
| 2 | **Qualité** | Erreurs, litiges, retouches, CSAT | Historique d'erreurs, réclamations | | | | Pas de coût unitaire par erreur |
| 3 | **Capacité** | Volume traitable sans embauche | Files d'attente, backlog, occupation | | | | Annoncer une capacité sans demande |
| 4 | **Vitesse** | Délais raccourcis, cycles accélérés | Temps de cycle, SLA, time-to-market | | | | Mesurer l'outil, pas le processus |
| 5 | **Argent** | Revenus additionnels, coûts évités | Facturation, coûts complets, churn | | | | Additionner des gains identiques |

## Vérification anti double comptage

1. **Paires suspectes à examiner** (cocher les paires où la même valeur pourrait être comptée deux fois) :
   - [ ] Temps ↔ Argent (les heures réallouées génèrent-elles le revenu ? → retenir UNE mesure)
   - [ ] Capacité ↔ Argent (le volume en plus est-il facturé ? → retenir le revenu)
   - [ ] Qualité ↔ Argent (les erreurs évitées sont-elles déjà dans le coût évité ?)
   - [ ] Vitesse ↔ Argent (les délais raccourcis sont-ils déjà dans les pénalités évitées ?)

2. **Décision** : pour chaque paire cochée, quelle mesure monétaire est retenue, et pourquoi ?
